# Tokens

Die CSS-Variablen aus `src/tokens/theme.css` sind die öffentliche Schnittstelle
des Themes. Eine App überschreibt sie auf `:root` — Burgwiss tut das pro Schule.
**Umbenennen oder Entfernen ist ein Breaking Change.**

export const Swatch = ({ name }) => (
    <div style={{ display: 'flex', alignItems: 'center', gap: 12, margin: '6px 0' }}>
        <div
            style={{
                width: 40,
                height: 40,
                borderRadius: 8,
                background: `var(--${name})`,
                border: '1px solid var(--border)',
            }}
        />
        <code>--{name}</code>
    </div>
);

Text auf einer getönten Fläche (`bg-success/10`) nutzt immer
`text-success-tint-foreground`, nie `text-success` — die volle Farbe erreicht
auf ihrer eigenen Tönung keinen AA-Kontrast. ESLint prüft das.
